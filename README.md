# Protocol: Bunker

Protocol: Bunker — это проект для развёртывания и запуска браузерной адаптации игры «Бункер» с онлайн-лобби, игровыми комнатами, настройками ведущего, режимами для стриминга и отдельными ссылками для зрителей и служебных оверлеев. Сам игровой процесс происходит в браузере: один человек поднимает игру у себя или на сервере, а остальные участники просто заходят по ссылке и играют через сайт.

Внутри репозитория находится всё, что нужно для хостинга игры:
- серверная часть;
- клиентское приложение;
- общие типы и логика;
- сценарии и игровой контент;
- стримерские и зрительские режимы;
- инфраструктура для локального запуска, self-host и релизной сборки.

Если коротко:
- игроки заходят в игру через браузер;
- хост поднимает игру локально, на телефоне или на сервере;
- стример получает встроенные инструменты для показа игры на трансляции;
- разработчик может дорабатывать механику, контент и интерфейс под свои задачи.

## Для кого

### Игроки
Для обычного игрока ничего скачивать и настраивать не нужно. Игру поднимает хост — на своём компьютере, телефоне или на сервере, в зависимости от выбранного варианта запуска, — а сама партия проходит в браузере по ссылке.

### Хосты / self-host
Этот репозиторий в первую очередь нужен для самостоятельного развёртывания игры со стороны хоста и её дальнейшей доработки. Здесь находится сервер, клиент, настройки запуска, сборка portable-версий и всё, что связано с поднятием игры у себя.

### Стримеры
В проекте уже предусмотрены элементы, нужные для вывода игры на стрим и её ведения: отдельные viewer/control-ссылки, spectator/read-only режимы, streamer mode и инструменты для OBS и оверлеев.

### Разработчики
Для тех, кто хочет изучать кодовую базу, вносить изменения, добавлять контент, править механику, локализацию, интерфейс или использовать проект как основу для своей версии игры.
