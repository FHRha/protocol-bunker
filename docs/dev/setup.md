# Настройка разработки

Этот документ описывает базовый локальный запуск Protocol: Bunker для разработки, проверки сборки и повседневной работы с репозиторием.

## Что нужно заранее

Перед началом убедись, что у тебя установлены:
- **Git**
- **Node.js** (актуальная LTS)
- **pnpm**

Репозиторий использует `pnpm` workspaces и корневые скрипты для запуска сразу нескольких частей проекта.

## Установка зависимостей

Клонируй репозиторий и установи зависимости из корня проекта:

`pnpm install`

## Базовый сценарий локального старта

### Запуск dev-режима

`pnpm dev`

Эта команда запускает сервер и клиент параллельно из корня репозитория.

### Сборка проекта

`pnpm build`

Используй её, если хочешь проверить, что проект собирается целиком.

### Проверка типов

`pnpm typecheck`

Полезно прогонять перед заметными изменениями и перед коммитами.

### Запуск собранного сервера

`pnpm start`

Эта команда запускает уже собранный сервер из `server/dist`.

## Полезные команды

### Сборка отдельных частей

Собрать только клиент:

`pnpm build:client`

Собрать только сервер:

`pnpm build:server`

### Интеграционные тесты

`pnpm test:integration`

Сейчас интеграционный набор включает websocket-проверки и тест установки/обновления.

### Проверка локализации

`pnpm locale:audit`

`pnpm locale:check`

Эти команды полезны при изменениях в интерфейсе, переводах и UI-строках.

### Сборка релизных пакетов

`pnpm pack:win`

`pnpm pack:linux`

`pnpm pack:linux:arm64`

`pnpm pack:desktop`

Эти команды используются для сборки релизных артефактов под разные платформы.

### Очистка артефактов

`pnpm clean`

Полезно, если нужно сбросить результаты прошлых сборок.
