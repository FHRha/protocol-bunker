# Чеклист ручной UI-проверки (релиз)

Используйте этот чеклист перед публикацией релизных артефактов.

## Базовый поток
1. Создать лобби, подключить 2-3 вкладки/устройства, запустить игру.
2. Проверить переподключение одного игрока в лобби и в игре.
3. Убедиться, что после открытия Overlay Control не создается ghost-игрок `CONTROL`.

## Роли и управление
1. Передать ведущего из шапки лобби.
2. Передать ведущего из панели Overlay Control.
3. Проверить, что CONTROL-действия недоступны не-CONTROL игрокам.
4. Проверить, что кнопки исхода бункера остаются у CONTROL.

## Ссылки и оверлеи
1. В блоке ссылок лобби проверить hide/show для:
   - ссылок приложения
   - overlay view
   - overlay control
   - зрительского стола
2. Проверить отображение строк LAN/WAN по текущему профилю.
3. Проверить валидность read-only ссылок зрителей.

## Мобильные проверки
1. Модалка голосования помещается по ширине и имеет вертикальный скролл.
2. Кнопки в шапке не вылезают и не накладываются друг на друга.
3. Блок "Твое досье" и DEV-кнопки +/- игрока удобны на узком экране.

## Спецусловия и голосование
1. Для карт обмена проверить, что в выборе:
   - сначала выбирается своя карта
   - затем карта/игрок цели
2. Проверить, что для multi-категорий (факты, багаж) доступны все инстансы карт.
3. Проверить, что "Храни в тайне" раскрывается с уведомлением и действует только на следующее голосование.
