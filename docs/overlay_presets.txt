Пресеты URL для OBS overlay (Протокол: Бункер)

Как использовать:
1) Самый простой путь: открыть Overlay Control и выбрать готовый пресет кнопками.
2) Альтернатива: вручную собрать URL по примерам ниже.
3) Подставьте свои значения вместо <ROOM> и <TOKEN>.

Важно:
- Параметры можно задавать двумя способами:
  - через Overlay Control (рекомендуется);
  - напрямую тегами/параметрами в URL overlay.
- Overlay Control умеет работать и с кнопками пресетов, и с Advanced шаблоном URL.
- В Advanced шаблоне поддерживаются теги: {ROOM}, {TOKEN}, {BG_PRESET}.

Базовый URL:
http://127.0.0.1:3001/overlay?room=<ROOM>&token=<TOKEN>

[Base]
URL: http://127.0.0.1:3001/overlay?room=<ROOM>&token=<TOKEN>
Comment: Базовый URL без дополнительных параметров.

[Debug]
URL: http://127.0.0.1:3001/overlay?room=<ROOM>&token=<TOKEN>&debug=1
Comment: Включает отладочную информацию поверх оверлея.

[Theme mint]
URL: http://127.0.0.1:3001/overlay?room=<ROOM>&token=<TOKEN>&theme=mint
Comment: Светло-мятная тема.

[Theme warm]
URL: http://127.0.0.1:3001/overlay?room=<ROOM>&token=<TOKEN>&theme=warm
Comment: Тёплая тема.

[Theme dark]
URL: http://127.0.0.1:3001/overlay?room=<ROOM>&token=<TOKEN>&theme=dark
Comment: Тёмная тема.

[Top FullHD]
URL: http://127.0.0.1:3001/overlay?room=<ROOM>&token=<TOKEN>&top=200
Comment: Высота верхней панели 200px (стандарт для FullHD-масок).

[Scale manual]
URL: http://127.0.0.1:3001/overlay?room=<ROOM>&token=<TOKEN>&scale=1.1
Comment: Ручной масштаб. Обычно лучше менять через Overlay Control.

[FullHD + BG preset]
URL: http://127.0.0.1:3001/overlay?room=<ROOM>&token=<TOKEN>&top=200&theme=mint&bgPreset=<BG_PRESET>
Comment: Использует выбранный пресет фона.

Пример Advanced шаблона (для Overlay Control):
http://127.0.0.1:3001/overlay?room={ROOM}&token={TOKEN}&top=200&theme=mint&bgPreset={BG_PRESET}

Примечание по фону:
- По умолчанию используется Default пресет фона.
- Если в Overlay Control выбран "Прозрачный", фон отключается полностью.
