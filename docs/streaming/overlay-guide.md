# Гайд по оверлеям

Этот файл — короткая памятка по `overlay` и `overlay-control`.

Если тебе нужен именно запуск с нуля, смотри:
- `streamer-quick-start.md`

## Что есть что

- `overlay` — ссылка для OBS;
- `overlay-control` — ссылка для управления оверлеем в браузере.

## Какой обычный порядок

1. Добавь `overlay` в OBS как **Browser Source**.
2. Открой `overlay-control` в браузере.
3. Внеси нужные изменения.
4. Нажми **`Save`**.
5. Проверь результат в OBS.

## Что можно менять в `overlay-control`

Обычно доступны такие блоки:

### Верхняя часть
Заголовки, подписи и верхние информационные блоки.

### Игроки
Отображение игроков, их блоков и связанных элементов.

### Дополнительные тексты
Короткие подписи и служебные текстовые блоки.

### Фон
Стандартный, прозрачный или другой доступный вариант.

## Главное правило

После любых изменений нажимай **`Save`**.

Без этого оверлей на стриме не обновится.

## Если что-то не работает

Проверь по порядку:

1. Нажат ли **`Save`**.
2. В OBS вставлена именно ссылка `overlay`.
3. Открыт правильный `overlay-control`.
4. Это та же самая комната.
5. Игра всё ещё запущена.

Если OBS показывает старую версию — обнови Browser Source.

## Примечание

Если тебе нужен просто рабочий стримерский режим, не пытайся настраивать всё сразу. Обычно достаточно:
- добавить `overlay` в OBS;
- открыть `overlay-control`;
- включить нужные блоки;
- нажать `Save`.
