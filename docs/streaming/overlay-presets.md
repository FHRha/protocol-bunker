# Пресеты оверлея

Этот файл — короткая памятка по пресетам и URL-параметрам для `overlay`.

Если тебе нужен обычный запуск:
- смотри `streamer-quick-start.md`

Если нужна краткая памятка по управлению:
- смотри `overlay-guide.md`

## Как использовать

Есть два обычных варианта:

### Вариант 1. Через `overlay-control`
Самый простой способ — открыть `overlay-control`, выставить нужные параметры и нажать **`Save`**.

### Вариант 2. Через URL
Если нужно быстро открыть готовый вариант, можно использовать ссылку `overlay` с нужными параметрами.

## Базовая идея

Обычно пресеты меняют:
- фон;
- размер и компоновку;
- внешний вид верхней части;
- дополнительные параметры отображения.

## Что чаще всего нужно стримеру

На практике обычно хватает трёх вариантов:

### Обычный фон
Подходит, если оверлей должен выглядеть как готовая самостоятельная сцена.

### Прозрачный фон
Подходит, если ты хочешь наложить элементы игры поверх своей сцены в OBS.

### Готовый пресет
Подходит, если нужно быстро получить уже настроенный вид без ручной подгонки.

## Когда использовать прозрачный фон

Прозрачный фон полезен, если:
- у тебя уже есть свой фон в OBS;
- ты хочешь встроить элементы игры в существующий дизайн трансляции;
- не нужен полный готовый фон от самого оверлея.

## Когда использовать обычный фон

Обычный фон лучше, если:
- нужно быстро запустить стрим без лишней настройки;
- хочется получить готовый вид сразу;
- не планируется отдельно собирать сцену вручную.

## Если используешь URL-параметры

Проверь, что:
- ссылка ведёт именно на `overlay`;
- открыта нужная комната;
- параметры не конфликтуют друг с другом;
- после изменений ты проверил результат в OBS.

## Практический совет

Если ты не уверен, какой вариант выбрать:
1. сначала запусти обычный `overlay`;
2. проверь, как он выглядит в OBS;
3. потом уже переходи к прозрачному фону или пресетам.

Так проще не запутаться.

## Если что-то выглядит странно

Проверь по порядку:
1. правильная ли ссылка используется;
2. та ли это комната;
3. не закэшировал ли OBS старую версию;
4. не смешаны ли несколько разных параметров сразу.

## Примечание

Этот файл специально сделан коротким. Если набор пресетов или URL-параметров в проекте изменится, сюда лучше добавлять только актуальные и реально используемые варианты, без перегрузки редкими кейсами.
