# Быстрый старт для стримера

Если тебе нужно просто вывести игру на стрим, делай так.

## Что понадобится

- запущенная игра;
- ссылка `overlay`;
- ссылка `overlay-control`;
- OBS.

## Шаг 1. Запусти игру

Сначала хост должен поднять игру и открыть нужную комнату.

## Шаг 2. Добавь оверлей в OBS

1. Открой OBS.
2. Добавь **Browser Source**.
3. Вставь туда ссылку `overlay`.
4. Поставь размер `1920x1080`.

Это и будет картинка для стрима.

## Шаг 3. Открой управление оверлеем

1. Открой ссылку `overlay-control` в браузере.
2. Через неё настрой, что должно показываться на стриме.

## Шаг 4. Внеси нужные изменения

Обычно достаточно:
- включить нужные блоки;
- проверить игроков;
- поменять тексты;
- выбрать фон.

## Шаг 5. Нажми `Save`

Это обязательно.

Пока ты не нажмёшь **`Save`**, изменения не появятся в оверлее на стриме.

## Если ничего не изменилось

Проверь по порядку:

1. Ты точно нажал **`Save`**.
2. В OBS вставлена именно ссылка `overlay`.
3. `overlay-control` открыт для той же комнаты.
4. Обнови Browser Source в OBS.
5. Проверь, что игра всё ещё запущена.

## Что проверить перед эфиром

Перед стримом убедись, что:
- оверлей открылся в OBS;
- игроки отображаются нормально;
- тексты и фон настроены;
- после `Save` изменения реально появляются.
