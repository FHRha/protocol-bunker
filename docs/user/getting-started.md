# Начало работы

Этот файл — короткий вход для обычного игрока и для хоста, который хочет быстро понять, как вообще запускается и используется Protocol: Bunker.

## Для обычного игрока

Если ты просто хочешь играть, обычно ничего скачивать не нужно.

Обычный сценарий такой:
1. Хост поднимает игру у себя или на сервере.
2. Даёт игрокам ссылку на комнату.
3. Игроки открывают её в браузере и подключаются к партии.

То есть для большинства игроков Protocol: Bunker — это не “приложение, которое надо ставить”, а игра, которая открывается по ссылке.

## Для хоста

Если ты хостишь игру, тогда уже нужен релиз проекта.

Обычно сценарий такой:
1. Скачать подходящую сборку.
2. Запустить игру у себя.
3. Открыть комнату.
4. Дать игрокам ссылку.

Подробные инструкции по самостоятельному запуску смотри в:
- `../host/self-hosting.md`

## Где брать сборки

Актуальные сборки публикуются в **GitHub Releases → Latest**.

В зависимости от платформы могут быть доступны:
- Windows;
- Linux;
- Android;
- другие варианты, если они поддерживаются текущей версией проекта.

Если ты обычный игрок, а не хост, этот шаг тебе обычно не нужен.

## Как проходит обычная партия

В упрощённом виде всё выглядит так:

1. Один человек поднимает игру.
2. Остальные заходят в браузере по ссылке.
3. Игроки подключаются к комнате.
4. Партия проходит внутри браузера.

## Что нужно игроку

Обычно достаточно:
- браузера;
- ссылки от хоста;
- стабильного подключения.

## Что делать, если игра не открывается

Проверь по порядку:

1. Точно ли хост уже поднял игру.
2. Правильная ли ссылка открывается.
3. Не истекла ли ссылка или не закрыта ли комната.
4. Работает ли интернет-соединение.
5. Помогает ли перезагрузка страницы.
6. Открывается ли ссылка в другом браузере.

Если проблема на стороне всех игроков сразу, чаще всего её нужно искать у хоста.

## Если ты вылетел из комнаты

Сначала попробуй просто открыть ссылку ещё раз.

Если не помогает:
- уточни у хоста, жива ли комната;
- проверь, не был ли перезапущен сервер;
- попробуй переподключиться заново.
