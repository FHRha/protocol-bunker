# OBS-оверлей: инструкция для стримера

## 1) Что тебе нужно
- `Overlay` (для OBS): `.../overlay?room=<ROOM>&token=<VIEW_TOKEN>`
- `Overlay Control` (для управления): `.../overlay-control?room=<ROOM>&token=<EDIT_TOKEN>`

Обычно обе ссылки уже есть в лобби и в логах сервера.

## 2) Как добавить в OBS
1. OBS -> `Sources` -> `+` -> `Browser`.
2. Вставь ссылку `overlay`.
3. Поставь размер `1920x1080`.
4. Нажми `OK`.

## 3) Как управлять оверлеем
1. Открой `overlay-control` в браузере.
2. Меняй нужные блоки и параметры.
3. Нажимай `Save`, иначе зритель не увидит изменения.

## 4) Фоны (текущее поведение)
- По умолчанию всегда используется `Default` пресет фона.
- Если выбрать `Прозрачный`, фон отключается полностью.
- Для фоновых пресетов автоматически подбирается layout под 4/8/12 игроков.

Папка фонов:
- `server/public/overlay/backgrounds/`

## 5) Маски и заготовки
- Маски для камер:
  - `docs/ДЛЯ СТРИМЕРОВ/Маска 32px/`
  - `docs/ДЛЯ СТРИМЕРОВ/Маска 48px/`
- Маски/вырезы под фон:
  - `docs/ДЛЯ СТРИМЕРОВ/Маски бекграундов/`
- Заглушки под фон:
  - `docs/ДЛЯ СТРИМЕРОВ/Под бекграунд заглушки/`

Эти маски нужны для камер, чтобы вебки игроков аккуратно и одинаково помещались в блоки игроков в оверлее.

Важно:
- шаблоны рассчитаны на стандартную высоту верхней панели `top=200`;
- я тестировал вариант `32px` маски для камеры - у меня работало нормально;
- если под вашу сцену не подходит, сделайте свои маски.

## 6) Пресеты URL и теги
Можно использовать:
- кнопки пресетов в Overlay Control;
- либо ручной URL/Advanced шаблон.

Поддерживаемые теги в шаблоне:
- `{ROOM}`
- `{TOKEN}`
- `{BG_PRESET}`

Подробные примеры:
- `docs/overlay_presets.txt`

## 7) Если что-то не работает
1. Проверь `room` и `token` в ссылке.
2. Проверь, что сервер запущен.
3. После правок в control нажми `Save`.
4. В OBS сделай `Refresh cache of current page` у Browser Source.
